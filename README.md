# Oriyo — космический интернет-магазин

Витрина, корзина, регистрация, личный кабинет, оформление заказов, админ-панель со статистикой.
Стек: Node.js + Express, PostgreSQL, чистый HTML/CSS/JS (без сборки).

## Страницы

- `/` — каталог: категории, поиск, добавление в корзину
- `/product?id=N` — карточка товара: количество, «В корзину» или «Купить сейчас»
- `/checkout` — оформление: только для вошедших пользователей, доставка курьером на дом (стоимость доставки оплачивает клиент), оплата при получении или картой
- `/register` — регистрация: ФИО, телефон, email, пароль
- `/login` — вход для покупателей и администратора (сессия в cookie, 30 дней)
- `/account` — профиль и история заказов
- `/admin` — командный центр, доступен только пользователю с ролью администратора

## Что умеет

**Витрина**
- Каталог с поиском и фильтром по категориям
- Корзина (хранится в браузере), контроль остатков
- Оформление заказа; цены и остатки проверяются на сервере
- Звёздный фон и космическая анимация

**Админ-панель** (`/admin`)
- Статистика: выручка, заказы, средний чек, заказы за 24 часа, график за 14 дней, топ товаров, товары с низким остатком
- Товары: добавление, редактирование, скрытие (удаление мягкое, история заказов сохраняется)
- Заказы: список и смена статуса (новый → оплачен → отправлен → доставлен / отменён)
- Защита от запрещённых товаров при сохранении

## Локальный запуск

```bash
npm install
export DATABASE_URL=postgres://user:pass@localhost:5432/oriyo
export FIRST_OWNER_EMAIL=admin@example.com
export FIRST_OWNER_PASSWORD=придумайте-надёжный-пароль
npm start
```

Откройте http://localhost:3000 и http://localhost:3000/admin.
При первом запуске в базе создаются таблицы и шесть демо-товаров.

## Деплой на Railway (24/7)

1. Создайте проект в Railway → **New Project → Deploy from GitHub repo** и выберите репозиторий.
2. Добавьте базу: **+ New → Database → PostgreSQL**.
3. В сервисе приложения откройте **Variables** и добавьте:
   - `DATABASE_URL` → **Add Reference** → `${{Postgres.DATABASE_URL}}`
   - `FIRST_OWNER_EMAIL` → email администратора
   - `FIRST_OWNER_PASSWORD` → пароль администратора (минимум 8 символов)
   - `NODE_ENV` → `production`
4. В **Settings → Networking** нажмите **Generate Domain**.
5. Railway сам запустит `npm start` (команда есть в `package.json`) и передаст порт через `PORT`.
6. Проверка: откройте `https://ваш-домен/health`, должен вернуться `{"status":"ok"}`.

Автодеплой работает при каждом push в ветку. Для постоянной работы 24/7 нужен платный план Railway, так как бесплатный лимит может останавливать сервис.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `DATABASE_URL` | строка подключения к PostgreSQL (даёт плагин Railway) |
| `FIRST_OWNER_EMAIL` | email администратора. Администратор входит через обычную страницу `/login` и сразу попадает в `/admin` |
| `FIRST_OWNER_PASSWORD` | пароль администратора. Чтобы сменить пароль, измените эту переменную и перезапустите сервис |
| `PGSSL` | `true`, если подключаетесь к базе по публичному адресу; для внутренней сети Railway не нужна |
| `PORT` | задаётся Railway автоматически |
| `STRIPE_SECRET_KEY` | секретный ключ Stripe (`sk_test_...` для тестов). Без него онлайн-оплата отключена |
| `STRIPE_WEBHOOK_SECRET` | секрет webhook (`whsec_...`). Webhook: `https://<домен>/api/stripe/webhook`, события `checkout.session.completed` и `checkout.session.expired` |
| `STRIPE_CURRENCY` | валюта Stripe, по умолчанию `rub` |
| `DELIVERY_FEE` | стоимость доставки курьером в рублях, по умолчанию 350 |
| `CLOUDINARY_URL` | строка `cloudinary://KEY:SECRET@CLOUD` для загрузки фото товаров. Без неё загрузка выключена |
| `TELEGRAM_BOT_TOKEN` | необязательно: токен бота для уведомлений о заказах |
| `TELEGRAM_CHAT_ID` | необязательно: ID чата, куда бот присылает заказы |

## Запрещённые товары

Список находится в `server.js`, массив `BANNED_KEYWORDS`. Если в названии, описании или категории найдено запрещённое слово, сервер не даёт сохранить товар. Это базовый фильтр, он не заменяет проверку.

Перед запуском продаж согласуйте список с юристом и правилами платёжного провайдера и проверьте законы вашей страны. Обычно под запрет попадают оружие и боеприпасы, наркотики и прекурсоры, поддельные документы и деньги, краденые товары, а также товары, которые нельзя продавать онлайн по закону (например, алкоголь и табак без лицензии, лекарства по рецепту).

## Что добавить для реального запуска

- **Оплата.** Доступны оплата при получении и оплата картой через Stripe Checkout. Перед продажей переключите ключи с тестовых на боевые. Подключите ЮKassa, CloudPayments или Stripe и переводите заказ в «оплачен» по webhook.
- **Уведомления.** Telegram уже поддерживается (см. переменные окружения); письма — следующим шагом.
- **Фото товаров.** Загрузка в S3 или Cloudinary вместо ссылок.
- **Безопасность админки.** Текущий вход простой: один пароль и токен. Для продакшена лучше добавить несколько администраторов, хранение токенов в БД с истечением срока и ограничение числа попыток входа.
- **Резервные копии.** Включите backup в плагине PostgreSQL на Railway.
